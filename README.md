# Self Forged

A phone app for workouts, diet, and habits. Log a gym session, track calories and protein, check off daily tasks, and see whether the day was completed.

Built with Expo and React Native. Logs stay on the device. There is no account system in place yet.

## Run

1. Install [Node.js](https://nodejs.org/)
2. In this folder, run:

```bash
npm install
npx expo start
```

3. Open the project in Expo Go, or an iOS or Android simulator

## What it does

- Gym: a split, check-in, a live session with rest timers, and prompts to raise or lower the weight
- Diet: calorie and protein targets, meals, and weight
- Tasks: daily, weekly, and monthly habits
- Streaks, charts, and a weekly recap across gym, diet, and habits
